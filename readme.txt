DraStic Plus – Features & Installation

DraStic Plus is an enhanced version of DraStic 2.5.2.2 for the R36S (ArkOS/dArkOS). It runs separately through Ports, so your normal DraStic installation, saves and settings remain untouched.

Installation / Update
1. Extract the ZIP file.
2. Copy the ports folder to your games SD card:
   - Primary SD card: /roms/ports
   - Secondary SD card: /roms2/ports
3. When updating, simply overwrite the existing files.

Your existing saves and settings are preserved.

Features

- Second Analog Stick Touch Control: Use the right stick to control the touchscreen with automatic touch-and-hold, eliminating the need to keep pressing a button. Ideal for first-person games, camera movement and other touch-based controls. Supports automatic edge re-grab for continuous movement.
- Picture-in-Picture Overlay: Display both DS screens simultaneously, with adjustable overlay size, position and opacity.
- Fake Microphone: Supports Stock, Blow, Tone and WAV modes, with adjustable loudness and pitch.
- Right Stick Stylus: Customize pointer speed, deadzone and response curve for smoother touchscreen navigation.
- Performance Tweaks: Optional frame timing, audio buffer and speed optimizations.
- Separate Save Management: Automatically copies existing saves on first launch and supports manual save selection, backups and restoration.
- Quick Controls: SELECT + Y opens the settings menu, SELECT + X toggles the screen overlay, and SELECT + START quits the game.
- Easy Navigation: Return to your game list after quitting, with your last played game highlighted.

All normal DraStic controls, menus and screen-switching features remain unchanged.
